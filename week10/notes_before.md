# week09/tools.py 함수 정리 (수정 전)

`week09/tools.py`에는 함수가 두 개 있습니다. 둘 다 영화진흥위원회(KOBIS) **일별 박스오피스 API**를 호출하고, API 키는 `secret.py`의 `API_KEY`에서 가져옵니다.

## 1. `get_boxoffice_rank_1(date)`
그 날짜의 박스오피스 1위 영화 제목을 돌려줍니다.

- **받는 것:** `date` (문자열): 8자리 날짜. 예: `"20260824"`
- **돌려주는 것:** 1위 영화 제목 (문자열). 예: `"오디세이"`
- **동작:** API가 돌려준 순위 목록의 첫 번째 항목(`movies[0]`)에서 `movieNm`을 꺼냅니다.

## 2. `get_movie_audience(date, title)`
그 날짜 순위 목록에서 특정 영화의 하루 관객 수를 돌려줍니다.

- **받는 것:**
  - `date` (문자열): 8자리 날짜. 예: `"20260824"`
  - `title` (문자열): 영화 제목. 예: `"오디세이"`
- **돌려주는 것:** 문자열
  - 영화를 찾으면 쉼표를 넣은 관객 수를 돌려줍니다. 예: `"186,587명"`
  - 못 찾으면 안내 문장을 돌려줍니다. 예: `"'오디세이' 은(는) 20260824 순위에 없습니다."`
- **동작:** 순위 목록(상위 10편)에서 `movieNm`이 `title`과 정확히 같은 영화를 찾아 `audiCnt`를 돌려줍니다.

## 눈에 띄는 점
- `get_movie_audience`에는 docstring이 없습니다. `get_boxoffice_rank_1`에만 있습니다.
- `get_boxoffice_rank_1`의 docstring 예시 날짜 `"20260000"`은 존재하지 않는 날짜(0월 0일)입니다.
- `audiCnt`는 **그날 하루** 관객 수입니다. 누적 관객 수는 `audiAcc`에 들어 있습니다.
- 제목은 띄어쓰기까지 정확히 같아야 찾을 수 있습니다.
- 오류 처리가 없습니다. 날짜 형식이 틀리거나 API 키가 잘못되거나 네트워크가 끊기면 예외가 그대로 발생합니다. 그날 순위 목록이 비어 있으면 `get_boxoffice_rank_1`에서 `IndexError`가 납니다.
